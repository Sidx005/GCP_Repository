# Budgets and Alerts
1. Create a Billing Account by choosing any mode of payment (Card preferable)
2. Go to Budgets and Alerts
3. Define the name of the budget
4. Select the services and project you want to apply (By default All Services (1777) selected)
5. Specify the amount you want to use as a threshold amount (If billing goes above or equal, gcp triggers a email alert)
